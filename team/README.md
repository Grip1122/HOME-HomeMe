## 项目背景

- 项目全称：**小觅HOME：虚拟孪生家庭具身空间物体定位（四人团队·AI辅助开发）**
- 项目题目：**HOME**，读音 "home me"，谐音英语 *homie*，即"伙伴"之意。
- 配套机器人：**小觅**。
- **视觉基点**：建筑高斯泼溅素材 `scene.ply`（1,996,390 个高斯点，449 MiB）。今后所有场景表现都以它为基点。因文件超过 GitHub 单文件 100 MB 上限，仓库只存清单与校验和，原始文件走网盘。详见 [`../assets/gaussian-splat/README.md`](../assets/gaussian-splat/README.md)。**注意：这份素材改变了场景的视觉起点（原方案是程序生成的灰盒），渲染路线与坐标标定需要先做三项验证，之后才能改 `layout_A.json`。**
- 一句话：用户用自然语言让虚拟管家"小觅"在三维家庭里找东西、拿东西、放东西；它会记住物品位置，记错了能被纠正，换了房间布局照样能干活。

**命名对照（重要）**：早期文档、部分测试与代码里把项目写作 "HomeTwin"、把机器人写作 "小方"，它们指的就是上面的 HOME 与小觅。以本段为准。仓库名 `hometwin` 和代码标识符暂不改名，避免一次改动牵连所有人的分支。

## 读完之后

1. 在 `02-roles.md` 里找到**你背后那个人**的角色。
2. 打开 `tasks/` 里对应的任务书（自包含，含逐步骤做法、红线、常见坑）。
3. **先别写代码**，向你的主人复述三件事，得到确认后再开工：
   - 你负责哪些目录，不得触碰哪些目录；
   - 你领取的第一个步骤要交付什么；
   - 你有哪些不确定、需要人确认的前提。
4. 每个步骤一个分支、一个 PR，PR 里勾选"已读完 team/ 两份文档"。
