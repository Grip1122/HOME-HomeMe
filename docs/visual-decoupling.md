# 3D 视觉表现规则：逻辑与视觉解耦

> 对应方案 2.1 抓取、1.1 相机。写给设计 A / 设计 B。目标：**抓取动画永远不暴露穿模与位置偏移**。

---

## 1. 基本原则

**逻辑判定与视觉表现完全分开。** 寻路网格外扩 0.25 米只保证“机器人身体不撞家具”；它不保证“手伸出去不穿进家具”。因此：

| 层 | 负责 | 不负责 |
|---|---|---|
| 逻辑层（`nav/` `robot/actions.js`） | 能不能抓、抓谁、状态转移、记忆更新 | 手长什么样、有没有碰到 |
| 视觉层（`robot/animation.js`） | 看起来像在抓 | 判定是否成功 |

**视觉层不得向逻辑层回传任何信息。** 抓取成败只由距离判定，动画只是“播出来”。

---

## 2. 抓取判定

```text
可抓取  ⇔  水平距离( 机器人.xz , 物体.xz ) < 1.0 m
```

- 用水平距离，忽略高度差（物体在桌面上，机器人在地面，高度不同是正常的）。
- 不满足时：先 `go(target)` 走到最近可达格，再重新判定；再不满足则返回 `{ok:false, reason:"too_far"}`。
- `layout` 示例里每个物体到最近可站格的距离 0.60–0.93 m，都满足该阈值（`tests/test_layout_checker.py` 持续校验，布局改动后超过 1.0 m 会直接报错）。

---

## 3. 固定相机：规避穿帮

相机使用**正交俯视，固定 45° 俯仰**，只允许平移与缩放，**禁止旋转与俯仰**。

| 项 | 取值 | 说明 |
|---|---|---|
| 投影 | `OrthographicCamera` | 无透视形变，手与家具的前后关系永远是“上方俯视” |
| 俯仰 | 45°（固定） | 看不到桌下、柜背、物体底面 |
| 偏航 | 固定 | 评委无法转到“穿帮角度” |
| 允许操作 | 平移、缩放 | 缩放范围限制在 0.7–1.5 倍 |
| 禁止 | 旋转、倾斜、第一人称 | 轨道控制器必须 `enableRotate=false`，并锁 `minPolarAngle = maxPolarAngle` |

这是“视觉防线”，不是“物理正确”。它的作用是让手臂在 Z 方向（深度）上的轻微穿插被视线遮挡。

> ⚠ 该方案**不能**消除穿模，只能让固定视角下肉眼察觉不到。若后续需要允许自由旋转，必须回到真正的 IK 或接触约束。

---

## 4. 抓取动画

| 项 | 取值 |
|---|---|
| 动画片段 | `Punch`，只取前半段 |
| 总时长 | ≤ 0.5 s（含淡入淡出 0.25 s） |
| 物体缩放 | 抓取瞬间缩放至 **0.4 倍**，放置后恢复 |
| 物体位置 | 携带锚点（机器人前上方） |
| 特效 | **无**。不加辉光、描边、粒子、光柱 |

**为什么不加发光特效**：发光会在物体与手之间形成高亮的“接触线”，等于给观众标出穿模位置。抓取阶段最好的表现就是“快、小、没有额外提示”。

> 目标物高亮（步骤 4.3）只用于“找到了”的时刻，不在抓取动画期间出现。两者时间上错开，不要叠加。

---

## 5. 挂载：必须保持世界变换

```js
// ✅ 正确：three.js 的 attach() 会重算局部变换，世界位置不变
carryAnchor.attach(objectMesh)

// ❌ 错误：add() 不改局部变换，物体会瞬移到锚点局部坐标的 (x,y,z)
carryAnchor.add(objectMesh)
```

放置同理：

```js
furnitureGroup.attach(objectMesh)          // 挂回家具，世界位置保持
objectMesh.position.y = furnitureTopY      // 再贴到台面高度（单独一步，便于测试）
objectMesh.scale.setScalar(1)              // 恢复缩放
```

**必须有的测试**：挂载前后记录物体世界坐标，断言差 < 1e-6。这条测试能抓住所有“用了 `add` 就瞬移”的 AI 生成代码。

## 6. 检查清单（设计 A / B 提交前自查）

- [ ] 抓取判定只用水平距离 < 1.0 m，不依赖动画回调
- [ ] 相机已锁旋转与俯仰；`enableRotate=false`
- [ ] 抓取动画 ≤ 0.5 s，物体缩放 0.4 倍，无任何发光/描边
- [ ] 挂载全部使用 `attach()`，代码里搜不到 `.add(objectMesh)` 形式的挂载
- [ ] 世界坐标前后一致测试存在且能变红
- [ ] 家具包围盒仍以 `layout.json` 为准，美术替换只换外观
