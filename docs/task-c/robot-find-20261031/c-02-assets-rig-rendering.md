### 1.1 源 → 世界坐标换算（唯一公式）

```
world.x = src.x + 0.35
world.y = −src.y + 0.03 + lift
world.z = −src.z − 0.30
```

对应 `scene-find.js:93` 的 `toWorld(src, lift)`。物件表中的 `src` 是源 Y-down 坐标，`world` 是按上式算出的 Y-up 世界坐标，两者都已落盘，便于交叉校验。

### 2.5 导航路径限位

三段式路径，避免直线穿越家具（`scene-find.js:575-592`）：

```
起点 → mid1 (start.x, 0.1, aisleZ) → mid2 (target.x, 0.1, aisleZ) → stop
aisleZ = 0.0
stop   = (target.x, 0.1, clamp(target.z + 0.8, −1.40, +1.40))
```

- 停靠点在目标 Z 方向外推 0.8 m，即**不压到物品上**。
- 路径点高度常量 0.1 仅用于路径插值，落地渲染仍为 y=0。
- 单段时长 `clamp(total × 300, 700, 1900)` ms。

### 3.1 识别口径（如实声明）

这是**几何 + 颜色**识别，不是语义分割。流程：5 cm X-Z 立柱 → 逐柱 Y 直方图 → 去除主导水平面（地面 / 桌面 / 层板）→ 4 cm 体素 26 邻域连通域聚类 → 尺寸与点数过滤 → HSV 颜色命名 + 包围盒形状分类 + 尺寸分档 → 0.18 m 内去重。

因此名称形如「黑色大长方体物体」而非「水杯」「遥控器」。要得到语义标签需引入 SAM / Grounding DINO / CLIP 一类模型，本轮未做。过滤阈值：点数 ≥ 60，最大边 0.06~0.55 m，最小边 ≥ 0.012 m。

### 4.2 材质贴图现状（重要缺口，不虚构）

**母版当前不使用任何位图贴图。** 机器人全部材质为纯色 PBR 参数（`color` + `roughness` + `metalness` + `emissive`），没有 albedo / normal / roughness / AO / metalness 贴图文件，因此：

- 不存在贴图文件，也就没有对应的贴图来源、许可、文件大小与 SHA-256 可填。
- 实景部分的"外观"来自 3DGS 高斯点自带的球谐 DC 颜色（`f_dc_0..2`，`C0 = 0.28209479177387814`），属于点云数据而非贴图资源。

若本轮验收要求交付真实位图贴图，需要先定材质方向再授权制作，这部分我不能用占位文件冒充已交付。当前可验收的是上表的材质参数，以及第 5 节的渲染参数。

### 4.3 物件颜色

物件不使用独立材质，其 `color` 字段为点云聚类的平均颜色，仅用于 UI 标记与结果卡配色，不参与 3D 着色。
