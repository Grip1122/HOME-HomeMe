# web/src/ui

小觅HOME 的交互界面层：HUD、任务状态、记忆面板、语音/文本输入、执行时间线及演示辅助视图。

- **品牌文案**：用户可见名称统一为“小觅HOME”，机器人名称为“小觅”。
- **边界**：UI 只消费既有事件与状态，不直接修改 `contracts/` 或场景坐标数据。
- **测试**：涉及 DOM 的测试文件需在首行声明 `// @vitest-environment jsdom`；其他测试维持默认 Node 环境，避免影响依赖 `file:` 资源读取的模块。
- **集成**：页面入口由 `web/src/main.js` 装配；桌面演示主界面以 `web/index.html` 为准。

目录责任边界和协作流程见仓库根目录 [`README.md`](../../../README.md)。
